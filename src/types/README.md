# FlowBoard Types

This module contains TypeScript type definitions for the FlowBoard application.

## Core Types

- **User** - Represents a team member
- **Task** - A work item with status, priority, and assignments
- **Project** - A container for related tasks
- **Activity** - An audit log entry
- **Comment** - A comment on a task

## Enums

- **Priority**: low, medium, high, critical
- **Status**: backlog, todo, in_progress, review, done
- **ProjectStatus**: active, archived, paused
